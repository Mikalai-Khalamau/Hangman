# Консольная игра "Виселица" (Hangman)

## 📌 Описание проекта
Классическая консольная игра «Виселица», в которой пользователь угадывает загаданное слово по буквам за ограниченное число попыток. Программа поддерживает два режима работы: интерактивный (пользовательский) и неинтерактивный (тестовый для автоматической проверки).

## 🛠 Технологии и реализация
* **Язык:** Python
* **Архитектура:** Разделение логики на игровой движок (`engine`), сессию игры (`game_session`), генератор слов и интерфейсы взаимодействия.
* **Что использовано:** Стандартные структуры данных Python, обработка пользовательского ввода с защитой от некорректных символов, модульное тестирование.
* **Изученные инструменты:** 
  * Принципы ООП и модульности в Python.
  * Написание юнит-тестов с использованием `pytest`.
  * Обработка аргументов командной строки (`argparse`).

## 🚀 Инструкция по запуску
1. Установите зависимости (если используется Poetry):
   ```bash
   poetry install
   ```
2. Запуск интерактивной игры:
   ```bash
   python -m src.main
   ```
3. Запуск тестов:
   ```bash
   pytest
   ```
